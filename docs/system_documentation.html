1. Executive Summary & Architecture Tenets

ShopFlow is an enterprise-grade multi-vendor e-commerce platform designed and built from scratch as an end-to-end solo initiative. The platform simulates high-throughput real-world commerce workloads across distributed, autonomous services while maintaining strict data consistency, transactional safety, and low-latency client experiences.

Two-Phase Inventory Lock

Concurrency-safe reservation locks (PENDING → COMMITTED / RELEASED) prevent overselling during checkout spikes.

Stripe Webhooks & Fallback

HMAC-verified webhooks decouple payment authorization from synchronous client requests, backed by client-side fallback order generators.

Multi-Vendor Partitioning

Strict role-based isolation ensures vendors manage independent catalog inventories and query scoped fulfillment pipelines.

Pinterest Editorial UI

Zero-dependency React 18 + TypeScript frontend with 3-column editorial grid, live swatches, size filters, and full INR (₹) localization.

9. Failure Modes & Resilience Patterns

Graceful Fallback Checkout

Decoupled modal with resilient client-side order reference generation prevents users from getting stranded during downstream hiccups.

Orphaned Lock Auto-Sweeper

Scheduled 60-second background worker automatically sweeps abandoned PENDING stock reservations past 15 minutes.

Spring Security /error Permitted

All microservices explicitly permit /error in SecurityFilterChain to ensure domain status exceptions (409, 400) dispatch properly.

Stateless Mesh Load Balancing

Netflix Eureka dynamic registry paired with OpenFeign client-side load balancing provides transparent routing without hardcoded IPs.
